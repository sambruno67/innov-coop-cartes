# Cartes hors connexion INNOV COOP Terrain

Ce depot public contient uniquement deux fonds de carte vectoriels OpenStreetMap pour les essais de l'application Android. Il ne contient aucune donnee de producteur ou de cooperative.

Telechargez le fichier `.pmtiles` du pays souhaite depuis la derniere release. Dans INNOV COOP Terrain : ouvrez un formulaire avec question polygone, choisissez « Importer un pack national vectoriel », selectionnez le fichier telecharge, puis « Voir la carte vectorielle hors connexion ». Le releve des limites continue a utiliser les positions GPS prises sur place.
